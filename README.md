# Matíz

Generador de paletas de colores aleatorias creado con JavaScript vanilla.

## Demo

[Ver Matiz online](https://color-palette-generator-rose-nine.vercel.app/)

## Funcionalidades

- Generación de paletas de 5 colores aleatorios.
- Visualización del código HEX de cada color.
- Copia del código HEX al portapapeles al hacer clic sobre un color.
- Mensaje de confirmación al copiar un color.
- Diseño responsive para dispositivos móviles.

## Tecnologías

- HTML 5
- CSS3
- JavaScript
- Manipulación del DOM
- Web Clipboard API
